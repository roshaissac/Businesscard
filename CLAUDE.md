# Project: Rosh Issac — Digital Business Card

Single self-contained `index.html` (no build step) deployed on GitHub Pages.
Edit the `ME` object in the `<script>` for contact details; brand colors live
in the `:root` CSS custom properties. Assets are generated with `sharp`.

## ⚠️ RECA COMPLIANCE — non-negotiable
- **"Issac Realty Team" must ALWAYS appear together with "Dreamhouse Realty Ltd."**
  Whenever the team name is shown (card, OG banner, README, any new surface),
  it must be immediately followed/accompanied by the brokerage line, e.g.
  *"Issac Realty Team — Associates of Dreamhouse Realty Ltd."*
  Never show the team name alone. This is a real-estate licensing requirement.
- The brokerage (Dreamhouse Realty Ltd.) must remain visibly disclosed on the
  card — currently the sticky bottom band (logo + copyright) and the body
  affiliation line both carry it. Do not remove either without keeping the
  disclosure elsewhere.

## Brand
- Deep black (`--ink #0f0f0f`) dominant; light orange (`--accent #ee8a4e`) as the
  accent; warm ivory surfaces. Serif for display name, system sans for body.

## Layout (app-shell)
- Fixed black top header (name/role/phone·email), scrolling white middle,
  sticky bottom brokerage/copyright band. Bar heights are measured by
  `fitBars()` into `--topbar-h` / `--band-h`; keep that wiring if restructuring.

## Assets
- Portrait crop for all face assets (avatar, icons, vCard photo, OG circle):
  `extract({left:1000,top:960,width:860,height:860}).modulate({brightness:1.12})`.
- The vCard photo is embedded as base64 (`PHOTO_B64`) — regenerate it whenever
  the portrait changes.
- `og.jpg` is the 1200×630 WhatsApp/SMS banner, generated by `/tmp/banner.js`.

## Privacy / performance
- Visitor-facing path must stay zero third-party calls (no CDNs on first paint).
  Capture Mode (Rosh-only) may lazy-load OCR libs on demand.
